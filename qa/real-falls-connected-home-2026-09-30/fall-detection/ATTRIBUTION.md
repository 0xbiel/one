# Dataset attribution and version reconciliation

The evaluated release is **GMDCSA-24 v2.1**, author Ekram Alam (2024), DOI [10.5281/zenodo.13354453](https://doi.org/10.5281/zenodo.13354453), released under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). The author-hosted [Zenodo API record](https://zenodo.org/api/records/13354453) explicitly identifies this dataset license.

The original GitHub tag `v2.1` points exactly to evaluated commit `5abac7693229900cf80f722e878fbb119211fc1c`. No dataset version or annotations were switched during publication. The repository README's v2.0 citation is older; v2.0 points to `d3edb5d8d5c1d047270c11139396796469d08fbc`. The v2.1 deposit states that CSV class/start/end timing metadata was modified.

Also credit the accompanying publication: Ekram Alam, Abu Sufian, Paramartha Dutta, Marco Leo and Ibrahim A. Hameed, *GMDCSA-24: A dataset for human fall detection in videos*, Data in Brief 57 (2024), 110892, [DOI](https://doi.org/10.1016/j.dib.2024.110892).

The GitHub repository separately includes an MIT notice (copyright 2024 Ekram Alam), retained in `dataset/LICENSE`. It is additional provenance, not a replacement for the dataset-specific CC BY 4.0 attribution above.

Preview changes: frames are resized, sampled, labeled and overlaid with model boxes/keypoints and benchmark captions. Cropped/resampled preview clips retain their source speed. These adaptations do not imply endorsement by the dataset authors. Raw dataset archives and model weights are not republished.
