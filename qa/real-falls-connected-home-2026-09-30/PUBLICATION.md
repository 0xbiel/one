# Compact publication scope

The owner approved this new QA branch and draft PR after attachment transfers failed. Both reports, the editable fall report, aggregate and clip-level scores, source/version/license provenance, generators, scoring/audit scripts and compact visual examples are preserved here. No production application code, sharing permissions, main branch, merge or deployment was changed.

## Included visuals

- Fall overview, six labeled still examples and three short annotated example clips
- Connected-home result graphic, four original query JPEGs and the generated five-kilobyte USDZ preview

The v2.1 dataset examples are credited under [CC BY4.0](fall-detection/ATTRIBUTION.md). Connected-home scenes are procedural and contain no third-party photographs.

## Deliberately omitted large payloads

Original fall-dataset videos, model weights, large per-frame inference caches, the full reproduction ZIP and the PDF copy are not uploaded. The editable DOCX and text report are included. The fall [README](fall-detection/README.txt) explains official retrieval and fresh inference/scoring; the omitted-artifact manifest retains checksums.

The complete connected-home exact-replay package was validated locally, but109 binary payload files are omitted from this compact branch. Its published replay inventory records expected files and hashes. **Exact no-model replay is not available from this branch alone.** Follow the connected-home README for generation/fresh-scoring instructions and the distinction between reconstruction and the original validated run.

Small visible previews were prioritized over another long binary-transfer batch. Numerical results were not rerun or changed during publication.
