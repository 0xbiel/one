What this can and cannot tell you

The page shows pose quality, model readiness, sequence score freshness, threshold, confirmation progress, and the gate reason. “Would emit” means the isolated debug tracker would create a fall_suspected / needs_review signal; it does not save an event or snapshot. This is not an accuracy certification.

To establish accuracy, collect representative, consented clips covering falls and ordinary activities, label each clip independently, replay them, and count false alerts and missed falls. Keep separate clips for threshold selection and final evaluation. Tune only after reviewing those results.
